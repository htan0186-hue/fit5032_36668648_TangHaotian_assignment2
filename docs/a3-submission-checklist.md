# FIT5032 A3 Submission Checklist

Use this checklist before uploading the final files to Moodle.

## Web Application Submission

- Project builds successfully with `npm run build`.
- GitHub repository is shared with the tutor.
- GitHub repository has at least three meaningful code commits.
- Production website opens correctly:
  `https://fit5032-assignment3.netlify.app/`
- Netlify environment variables are configured:
  - `VITE_FIREBASE_API_KEY`
  - `EMAIL_FROM`
  - `SILVERLINK_EXPORT_TOKEN`
- Submission template includes:
  - GitHub username
  - GitHub repository link
  - deployed Netlify application link
  - A3 shared repository confirmation
  - BR D/E/F self-evaluation
  - BR F.1 innovative feature choices
  - Google Drive demo video link

## Demo Video

- Video file name follows the required pattern:
  `Haotian-Tang-36668648-A3.mp4`
- Video shows BR D, E and F functionality.
- Google Drive permissions allow the tutor or Monash users to view the video.
- The video link is pasted into the submission template.

## Research Report

- Report is exported as a single PDF.
- Topic is clearly stated.
- Sections are included:
  - Introduction
  - Main Body
  - Reflection
  - Conclusion
  - Acknowledgement of AI use
  - References
- Word count is within the 1000 word target and 1100 word grace limit,
  excluding references.
- References are in IEEE style and include at least five sources.
- At least two sources are academic literature.

## Final Moodle Upload

- Web application submission is a zip file containing the app and completed
  submission template.
- Research report is submitted separately as a PDF.
- Download or preview both uploaded files after submission to confirm they are
  readable.
